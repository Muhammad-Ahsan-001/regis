Scroll the page — the animation is bound to scroll progress.

Integration: the animation exposes its API as window.InkFlowInstances['ifs'] and on the SVG element itself (svgElement.inkflow). Methods: play(), pause(), stop(), restart(), reverse(), seek(ms), playSegment(name), setSpeed(x), setInput(name, value), destroy(). This file is fully self-contained and makes no network requests.
