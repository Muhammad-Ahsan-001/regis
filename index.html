Stop 1 of 5 · About

From pre-med to production code.

I came to computer science after two years of pre-med, which means I still think about software the way a clinic thinks about a patient: what is actually going on, and what is the smallest thing that would fix it.

Most of what I build is for small businesses that have never had software made for them. Tax agencies, aluminium fabricators, private schools, consultancies. Offline-first, PKR-native, WhatsApp-friendly, and boring in all the right places.

On campus I help run the IEEE Computer Society chapter, where I plan the semester, run hands-on workshops, and try to make the first year less confusing for the people arriving after me.

Stop 2 of 5 · Work

Selected work.

Seven projects. Most were built for a specific business with a specific problem; two are tools I needed myself.

01 / 07 Tax software

FileDesk

Client, case and payment management for Pakistani tax agencies. Four tax calculators and a fee estimator run in the browser, the ledger is immutable, and invoices and receipts are generated client-side. A Chrome extension fills exactly two fields on FBR portal login pages.

  • Fastify
  • PostgreSQL
  • React
  • Chrome MV3
Visit the site
02 / 07 Indoor navigation

CS Indoor Navigator

Indoor 3D navigation for a four-floor, 80-room department building. Pick a start and a destination; A* routes across floors by stairs or the elevator, with a route line, a minimap and written directions. The plan is drawn in a browser editor, and the graph and Blender model generate from it.

  • React Three Fiber
  • TypeScript
  • Blender
  • PWA
Open the navigator
03 / 07 Offline PWA

The Aluminium Pro

Offline-first quotation software for Pakistani aluminium fabricators. A shop-front measurement becomes glass cutting sizes, D-48 and U SEC material, hardware counts and a price, then four PDFs rendered on the phone and shared over WhatsApp. Syncs to the server when there is signal.

  • React
  • Fastify
  • Prisma
  • Workbox

In development

04 / 07 Campus platform

IEEE CS Student Resource Hub

Chapter site for IEEE Computer Society at COMSATS Islamabad, with a 28-screen staff portal editing the content behind it. Indoor wayfinding routes four floors of the CS block with Dijkstra over a 271-node graph.

  • React 19
  • Supabase
  • TypeScript
  • Tailwind CSS
Visit the site
05 / 07 School platform

INTELLA

Multi-tenant school management for Pakistani private schools: a database per school, seven role portals in one app. Fees ledger, offline attendance, exams and result cards, seating plans, quizzes. Every route past login declares a permission, and a generated test checks 113 codes against 7 roles.

  • React 19
  • Fastify
  • PostgreSQL
  • Drizzle

In development

06 / 07 Internal CRM

Top7 Consultants CRM

Role-based CRM for a study-abroad consultancy with Faisalabad and Lahore branches. Twelve portals over a nine-stage application lifecycle, twelve SLA rules that escalate unacknowledged breaches, and a payment gate that holds visa work until the second installment clears.

  • React
  • TypeScript
  • Express
  • Gemini API

Local demo

07 / 07 Creative tool

InkFlow Studio

Browser studio for pressure-sensitive vector drawing, keyframe animation and scroll- or pointer-bound interaction. Exports standalone animated SVGs with a dependency-free runtime embedded inside them. The signature on this site was exported through it.

  • TypeScript
  • Vite
  • Zustand
  • SVG
